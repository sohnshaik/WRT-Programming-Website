Loops

For loops, foreach loops, and the very important reason while loops are banned from robot code.

What is a Loop?

A loop repeats a block of code until some condition is no longer true. Instead of writing the same line 50 times, you write it once and tell Java how many times to run it.

In robot code, loops show up everywhere — scanning through arrays of sensor values, running a set of motor configs at startup, iterating over a list of auto steps. You need to be comfortable with all of them.

For Loops

The for loop is the workhorse. Use it when you know exactly how many times you want to repeat something.

java
// Structure: for (start; condition; step)
for (int i = 0; i < 5; i++) {
    System.out.println("Loop #" + i);
}
// Output: Loop #0, Loop #1, Loop #2, Loop #3, Loop #4
Init
int i = 0
Runs once at the start. Declares the loop variable. Almost always starts at 0 because arrays are zero-indexed.
Condition
i < 5
Checked before each iteration. Loop keeps going while this is true. When it's false, the loop exits.
Step
i++
Runs after each iteration. Usually increments. Can decrement (i--) to loop backwards.

Infinite loop warning: If your condition never becomes false, the loop runs forever and your program freezes. for (int i = 0; i >= 0; i++) — notice the condition never fails. This is a common mistake. Always double-check your condition.

Foreach Loops

The foreach loop is a cleaner way to loop through every item in an array when you don't need the index. It's less code and harder to mess up.

java
double[] motorSpeeds = {0.5, 0.75, 1.0, -0.5};

// Foreach — read each value, can't change the array
for (double speed : motorSpeeds) {
    System.out.println("Speed: " + speed);
}

// Normal for — use this if you need to MODIFY the array
for (int i = 0; i < motorSpeeds.length; i++) {
    motorSpeeds[i] = motorSpeeds[i] * 0.8; // reduce all speeds by 20%
}

Foreach gotcha: The foreach loop gives you a copy of each element, not the actual array slot. Modifying the copy doesn't change the original array. If you need to change values, use a regular for loop with an index.

The While Loop — and Why It's Banned

A while loop repeats as long as a condition is true. In theory, nothing wrong with it. In robot code, it's a trap.

java — how a while loop works
int i = 0;
while (i < 5) {
    System.out.println("i = " + i);
    i++;
}
// Works fine in regular Java programs

DO NOT use while loops in robot code. Here's why: FRC robots run on a loop-based framework. The robot's main loop calls your code every 20ms. If your code has a while loop inside it that gets stuck — waiting for a sensor, waiting for a button — it blocks the entire robot loop. The robot stops responding to the driver. Motors don't update. The watchdog timer fires. The robot dies.

This is not a theoretical concern. It has happened. Don't be the person who learns this during a match.

What to use instead: State machines, command-based architecture, and boolean flags. You'll learn all of this in the offseason FRC phase. For now, just remember: for loops only in robot code.

Coding Challenge

⚡ Challenge — Sensor Average
Use a for loop to process a real FRC-style array

Given an array of distance sensor readings (in inches):
double[] readings = {12.4, 13.1, 11.8, 14.0, 12.7};

Using a regular for loop (not foreach):
1. Calculate the sum of all readings
2. Calculate and print the average
3. Find and print the maximum reading

Bonus: Print a warning if any reading is below 12.0 inches.

solution
double[] readings = {12.4, 13.1, 11.8, 14.0, 12.7};

double sum = 0;
double max = readings[0]; // start with first value

for (int i = 0; i < readings.length; i++) {
    sum += readings[i];

    if (readings[i] > max) {
        max = readings[i];
    }

    // Bonus: warn if below 12 inches
    if (readings[i] < 12.0) {
        System.out.println("Warning: reading [" + i + "] is low: " + readings[i]);
    }
}

double average = sum / readings.length;
System.out.println("Average: " + average);
System.out.println("Max: " + max);
