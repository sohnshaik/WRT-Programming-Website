The Basics

Variables, data types, operators, scope, and writing code that other people can actually read.

Variables

A variable is a named container for a value. You give it a type, a name, and usually a starting value. From that point on, you can use the name anywhere in that variable's scope.

In FRC, you use variables constantly — motor IDs, speeds, sensor readings, flags. Naming them well is half the job.

java
// Basic variable declaration
int motorID = 1;
double motorSpeed = 0.75;
boolean isRunning = false;
String subsystemName = "Drivetrain";

// final = constant, can never change after this line
final int MAX_MOTOR_ID = 20;

FRC connection: In robot code you'll see a Constants.java file full of final variables — motor IDs, gear ratios, PID values. That's this concept, just organized into one place.

Data Types

Every variable in Java has a type. Types tell Java how much memory to use and what operations are valid. There are two categories: primitive (built-in, lowercase) and non-primitive (objects, uppercase).

TypeCategoryExample valueFRC use
intPrimitive5, -3, 1000Motor IDs, counter values
doublePrimitive0.75, -1.0, 3.14Motor speeds, sensor readings
booleanPrimitivetrue / falseButton state, limit switch
StringNon-primitive"Drivetrain"Subsystem names, logging

Type Casting

Sometimes you need to convert between types. Going from a small type to a bigger one (like int → double) happens automatically. Going the other direction requires you to explicitly cast it — and you lose some precision.

java
// Implicit (automatic) — int fits inside double, no info lost
int ticks = 500;
double position = ticks; // fine, becomes 500.0

// Explicit (manual) — double → int, decimal part gets chopped
double sensorReading = 3.87;
int roundedDown = (int) sensorReading; // becomes 3, not 4

// FRC example: encoder returns double, you need an int index
double encoderTicks = getEncoder().getPosition();
int slot = (int) encoderTicks;

Operators

Operators let you do math and comparisons. You'll use these in almost every line of robot code.

Math operators
+ − * / %
% is remainder (modulo). 5 % 2 = 1. Useful for cycling through indices.
Assignment
+= −= *= /=
speed += 0.1 is shorthand for speed = speed + 0.1. You'll write this constantly.
Increment / Decrement
++ −−
i++ adds 1. i-- subtracts 1. Used in every for loop you'll ever write.
Comparison
== != < > <= >=
These return a boolean. == checks equality; don't mix it up with = (assignment).

Writing Readable Code

We have a lot of programmers on this team. Everyone thinks differently. If your code is a mess, the person debugging it at 11pm before a competition is going to have a very bad time — and that person might be you.

java — bad vs good
// BAD — what does any of this mean?
double x1 = 0.8;
int y = 3;
boolean f = true;

// GOOD — self-documenting
double maxShooterSpeed = 0.8;
int shooterMotorID = 3;
boolean isShooterEnabled = true;

Naming rules: Variables and methods → camelCase. Classes → PascalCase. Constants → SCREAMING_SNAKE_CASE. Never use Java reserved words like int, class, for, boolean as names.

Scope

A variable only exists inside the { } block it was declared in. Declare a variable inside an if block and you can't use it outside of that block.

java
void example() {
    double speed = 0.5; // exists for the whole method

    if (speed > 0.3) {
        boolean isFast = true; // only exists inside this if block
        System.out.println(isFast);
    }

    // System.out.println(isFast); ← ERROR: isFast out of scope here
}

Knowledge Check

Coding Challenge

⚡ Challenge — Motor Calculator
Apply variables, types, and operators in a mini FRC scenario

Write a short Java snippet that does the following:

1. Declare a final double called GEAR_RATIO set to 8.46
2. Declare a double called motorRPM set to 5400.0
3. Declare a double called wheelRPM and calculate it as motorRPM / GEAR_RATIO
4. Cast wheelRPM to an int and store it in wheelRPMInt
5. Add a single-line comment above each line explaining what it does

solution
// Gear ratio between motor and wheel shaft
final double GEAR_RATIO = 8.46;

// Free spin speed of the Falcon 500 motor
double motorRPM = 5400.0;

// Actual wheel speed after the gear reduction
double wheelRPM = motorRPM / GEAR_RATIO;

// Truncated to int — loses decimal precision
int wheelRPMInt = (int) wheelRPM;
