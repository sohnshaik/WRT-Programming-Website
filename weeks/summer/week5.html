OOP — Classes & Objects

The most important week in this course. Everything in FRC robot code is a class. If you understand this week cold, the rest falls into place.

Why this matters: Every subsystem on our robot is a class. Drivetrain.java, Shooter.java, Coral.java — all classes. When you add a motor to a subsystem or write a method to control it, you're doing exactly what this week teaches you.

What is a Class?

A class is a blueprint. It defines what data something holds and what it can do. You write the blueprint once, then create as many objects from it as you need.

An object is one specific instance built from that blueprint. If Motor is a class, then leftDriveMotor and rightDriveMotor are two separate objects — each with their own ID and speed.

java — a simple Motor class
public class Motor {

    // Instance variables — data each Motor object holds
    private int id;
    private double speed;
    private boolean isInverted;

    // Constructor — runs when you create a new Motor
    public Motor(int id, boolean isInverted) {
        this.id = id;
        this.isInverted = isInverted;
        this.speed = 0.0; // motors start stopped
    }

    // Method — something a Motor can do
    public void setSpeed(double newSpeed) {
        this.speed = isInverted ? -newSpeed : newSpeed;
    }

    public double getSpeed() {
        return speed;
    }
}
java — creating objects from the class
// Create two Motor objects — each is its own independent instance
Motor leftMotor = new Motor(1, false);
Motor rightMotor = new Motor(2, true); // inverted

leftMotor.setSpeed(0.5);
rightMotor.setSpeed(0.5);

System.out.println(leftMotor.getSpeed());  // 0.5
System.out.println(rightMotor.getSpeed()); // -0.5 (inverted!)

Parts of a Class

Instance Variables
Data the object stores
Each object gets its own copy. leftMotor.id and rightMotor.id are different numbers.
Constructor
Runs when you use new
Same name as the class. No return type (not even void). Used to set initial values.
Methods
Things the object can do
Behaviors. setSpeed(), stop(), getPosition() — all methods.
this keyword
Refers to the current object
this.speed means the instance variable. Needed when a parameter has the same name.

Access Modifiers & Encapsulation

Encapsulation means keeping a class's data private and only allowing access through its methods. This protects your data — nobody can accidentally set a motor speed to 500 if you validate it in setSpeed().

ModifierWho can access itWhen to use
publicAnyone, anywhereMethods you want others to call
privateOnly inside this classInstance variables (almost always)
protectedThis class + subclassesWhen you expect inheritance
java — encapsulation with getters and setters
public class Shooter {
    private double targetRPM; // private — can't set from outside directly

    // GETTER — read the value
    public double getTargetRPM() {
        return targetRPM;
    }

    // SETTER — set the value, with validation
    public void setTargetRPM(double rpm) {
        if (rpm < 0 || rpm > 6000) {
            System.out.println("Invalid RPM, ignoring");
            return;
        }
        this.targetRPM = rpm;
    }
}

Coding Challenge

⚡ Challenge — Build a Subsystem Class
Design a complete class the way you'd actually write it in robot code

Write a class called Intake that represents an intake subsystem. It should have:

Private fields: int motorID, double speed, boolean isRunning

Constructor: Takes a motorID, sets speed to 0.0 and isRunning to false

Methods:
— start(double speed) — sets the speed and marks isRunning as true
— stop() — sets speed to 0.0 and isRunning to false
— isRunning() — returns the boolean
— getSpeed() — returns the current speed

Then create two Intake objects and test your methods.

solution
public class Intake {
    private int motorID;
    private double speed;
    private boolean isRunning;

    public Intake(int motorID) {
        this.motorID = motorID;
        this.speed = 0.0;
        this.isRunning = false;
    }

    public void start(double speed) {
        this.speed = speed;
        this.isRunning = true;
    }

    public void stop() {
        this.speed = 0.0;
        this.isRunning = false;
    }

    public boolean isRunning() { return isRunning; }
    public double getSpeed() { return speed; }
}

// Testing it:
Intake frontIntake = new Intake(5);
Intake backIntake  = new Intake(6);

frontIntake.start(0.8);
System.out.println(frontIntake.isRunning()); // true
System.out.println(backIntake.isRunning());  // false — separate object!
